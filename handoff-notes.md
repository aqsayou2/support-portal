## Git workflow
- **Commit:** Saves a snapshot of changes in the local Git repository.
- **Push:** Uploads local commits to GitHub.
- **Pull:** Downloads and integrates changes from the remote repository.
- **Origin:** The name of the remote repository hosted on GitHub.
